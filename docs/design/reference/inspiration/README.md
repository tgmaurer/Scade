# Inspiration

Screenshots of other apps worth stealing ideas from. Empty until they're added.

Ideas only. Nothing here is a target, and nothing here is a licence to
reproduce another app's design — the point is to identify *why* something
works so the reason can be applied to Scade's own screens.

## Naming

```
<app-name>-<what-it-shows>.png
```

Examples: `things-sidebar.png`, `reeder-list-density.png`,
`fantastical-empty-state.png`.

Name the file for what you want from it, not just for the app. Six months from
now `things-3.png` says nothing; `things-sidebar-grouping.png` says why it's
in the folder.

## Say what you want from it

A screenshot alone is ambiguous — it's rarely obvious whether the interesting
part is the type scale, the spacing, the colour, or the interaction. A sibling
`.md` with the same basename, or a line added to this README, closes that gap:

```markdown
### things-sidebar-grouping.png
The section headers. Quiet enough to scan past, distinct enough to anchor —
Scade's sidebar currently gives sections the same weight as rows.
```

One or two sentences is plenty.
